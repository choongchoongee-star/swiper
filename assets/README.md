# 아트 리소스 생성 요청서

그림을 폴더에 넣으면 게임이 **자동으로** 반영합니다. 한 장씩 넣어도 되고, 없는 그림은 대체본이 나옵니다.

## 넣는 곳
| 용도 | 폴더 | 파일명 | 없을 때 |
|---|---|---|---|
| 표정 6종 | `assets/` | `cat-<표정>.png` | 코드로 그린 SVG 고양이 |
| 대성공·대실패 이펙트 | `assets/fx/` | `great.png` `terrible.png` | 그 표정의 고양이 |
| 엔딩 그림 | `assets/endings/` | `<엔딩 id>.png` | 고양이 그림 + 이모지 |
| 카드 그림 | `assets/cards/` | `<카드 id>.png` | 기본 표정(`cat-idle`) |
| 왕관 | `assets/` | `crown.png` | SVG 왕관 |

## 요청하는 방법
1. 아래 **요청 하나**의 코드 블록만 통째로 복사해 이미지 생성 AI에 넣습니다. **여러 개를 한꺼번에 넣지 마세요.**
2. 나온 이미지를 `assets/raw/` 폴더에 저장합니다. 파일명은 그대로 둬도 됩니다.
3. 제가 칸을 잘라 이름을 붙여 배치합니다.

**칸 위의 제목은 그대로 두셔도 됩니다.** 어느 칸이 어느 그림인지 확인하는 용도이고, 자를 때 제가 제목 줄을 잘라냅니다.

## 진행 현황
| 용도 | 진행 |
|---|---|
| 표정 | **6 / 6** ✅ |
| 왕관 | **1 / 1** ✅ |
| 구조 엔딩 | **4 / 4** ✅ |
| 대성공·대실패 이펙트 | **2 / 2** ✅ |
| 엔딩 | **31 / 31** ✅ |
| 카드 | **101 / 101** ✅ |
| 선택 결과 카드 | **14 / 14** ✅ |
| 특수 카드 | **0 / 3** |

# 남은 요청 1개

> ### 특수 카드
> 인생 연장 · 행운의 클로버 · 검은 고양이의 시련 세 장은 아직 전용 그림이 없어,
> 기본 표정 고양이가 대신 나오고 있습니다.

### 요청 1 / 1 · 특수 카드

<sub>잘라낼 파일 — 복사하지 않아도 됩니다</sub>
- 1번 칸 → `extend.png`
- 2번 칸 → `clover.png`
- 3번 칸 → `trial.png`

```
아래 3개 장면을 한 장의 이미지에 3열 × 1행 격자로 그려줘.

[그림체]
굵고 균일한 검정 펜선 아웃라인(선 굵기 일정, 끝이 둥글게 마감)으로 그린 귀여운 주황 줄무늬 고양이 캐릭터.
완전히 납작한 플랫 채색 — 음영·그라데이션·질감·입체감 없음. 카카오톡 이모티콘처럼 단순하고 둥근 형태.
흰색 배와 앞발, 점처럼 작고 단순한 눈, 작은 분홍 코, 옅은 볼터치, 짧은 수염.

[배경 — 가장 중요]
**배경을 그리지 말 것.** 하늘·벽·바닥·풀밭·길·방 안 같은 배경을 일절 칠하지 말고,
캐릭터와 그 장면에 꼭 필요한 소품(밥그릇·둥지·나뭇가지 등)만 그릴 것.
바닥 선, 그림자 바닥, 장면을 감싸는 네모 액자도 넣지 말 것.
그 여백은 전부 실제 투명(알파 채널)이어야 한다.
투명을 나타내는 회색 체크무늬를 그림으로 그려 넣지 말 것.
칸을 나누는 흰색 판이나 테두리 선도 넣지 말 것. 칸 사이는 그냥 비워둘 것.
(게임 화면의 살구색 배경 위에 캐릭터만 떠 있게 올릴 것이라 배경이 있으면 쓸 수 없다)

[칸 구성]
각 칸 위쪽에 그 장면의 제목을 한 줄로 적어줄 것. 제목은 아래 목록의 문구를 그대로 쓸 것.
칸마다 캐릭터가 가운데 오도록, 칸끼리 넉넉히 띄울 것.

[장면 목록]

1. 인생 연장 — 실뭉치를 앞발로 굴리며 신이 난 고양이, 주변에 풀린 실 가닥
2. 행운의 클로버 — 네 잎 클로버를 입에 물고 눈을 반짝이는 고양이
3. 검은 고양이의 시련 — 눈만 노랗게 빛나는 검은 고양이와 마주 선 주황 고양이
```
