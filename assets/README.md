# 아트 리소스 생성 요청서

그림을 폴더에 넣으면 게임이 **자동으로** 반영합니다. 한 장씩 넣어도 되고, 없는 그림은 대체본이 나옵니다.

## 넣는 곳
| 용도 | 폴더 | 파일명 | 없을 때 |
|---|---|---|---|
| 표정 6종 | `assets/` | `cat-<표정>.png` | 코드로 그린 SVG 고양이 |
| 대성공·대실패 이펙트 | `assets/fx/` | `great.png` `terrible.png` | 그 표정의 고양이 |
| 엔딩 그림 | `assets/endings/` | `<엔딩 id>.png` | 고양이 그림 + 이모지 |
| 카드 그림 | `assets/cards/` | `<카드 id>.png` | 기본 표정(`cat-idle`) |
| 왕관 | `assets/` | `crown.png` | SVG 왕관 |

## 요청하는 방법
1. 아래 **요청 하나**의 코드 블록만 통째로 복사해 이미지 생성 AI에 넣습니다. **여러 개를 한꺼번에 넣지 마세요.**
2. 나온 이미지를 `assets/raw/` 폴더에 저장합니다. 파일명은 그대로 둬도 됩니다.
3. 제가 칸을 잘라 이름을 붙여 배치합니다.

**칸 위의 제목은 그대로 두셔도 됩니다.** 어느 칸이 어느 그림인지 확인하는 용도이고, 자를 때 제가 제목 줄을 잘라냅니다.

## 진행 현황
| 용도 | 진행 |
|---|---|
| 표정 | **6 / 6** ✅ |
| 왕관 | **1 / 1** ✅ |
| 조기 사망 엔딩 | **4 / 4** ✅ |
| 대성공·대실패 이펙트 | **2 / 2** ✅ |
| 엔딩 | **31 / 31** ✅ |
| 카드 | **78 / 101** |

(장면 자체에 필요한 배경 — 방 안, 창밖, 골목 같은 것 — 은 그려도 됨)

[칸 구성]
각 칸 위쪽에 그 장면의 제목을 한 줄로 적어줄 것. 제목은 아래 목록의 문구를 그대로 쓸 것.
칸마다 캐릭터가 가운데 오도록, 칸끼리 넉넉히 띄울 것.

[장면 목록]

1. 골목 끝의 사람 — 늘 같은 자리에 앉아 있는 사람이 있다. 오늘은 나를 보고 자리를 내준다.
2. 장마 — 비가 며칠째 그치지 않는다. 골목이 온통 물이다.
3. 폭염 — 아스팔트가 발바닥을 태운다. 그늘이 하나도 없다.
4. 자전거 — 소리도 없이 자전거가 코앞까지 왔다.
5. 유리창 — 저쪽에 새가 보인다. 앞이 뚫려 있는 줄 알았는데.
6. 족제비 — 길고 날렵한 짐승이 이빨을 드러낸다. 개보다 빠르다.
