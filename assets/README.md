# 고양이 그림 넣는 곳

이 폴더에 아래 6개 파일을 넣으면 게임이 자동으로 SVG 대신 그림을 씁니다.
하나라도 없으면(정확히는 `cat-idle.png`가 없으면) 전부 기존 SVG로 그립니다.

| 파일 | 표정 | 언제 나오나 |
|---|---|---|
| `cat-idle.png` | 평범한 표정 | 카드가 처음 뜰 때 |
| `cat-happy.png` | 기분 좋음 | 성공 |
| `cat-proud.png` | 우쭐함 | 대성공, 성장 단계 진입 |
| `cat-sad.png` | 시무룩 | 실패, 조기 엔딩 |
| `cat-scared.png` | 놀람 | 위험한 일을 겨우 넘겼을 때 |
| `cat-hurt.png` | 다침 | 대실패 |

## 파일 조건
- **투명 배경 PNG**, 정사각형(예: 512×512), 한 장당 300KB 이하 권장
- **6장의 고양이가 같은 캐릭터로 보여야 합니다** — 색·무늬·굵기가 흔들리면 표정이 바뀔 때마다 다른 고양이처럼 보입니다
- 자세와 크기를 6장 모두 똑같이 맞추면 표정만 바뀌는 것처럼 자연스럽습니다

## 이미지 생성 프롬프트 (그대로 복사해서 쓰세요)

먼저 기준이 되는 한 장을 만듭니다.

> 귀여운 주황색 줄무늬 길고양이 캐릭터 일러스트. 손으로 그린 듯한 굵고 균일한 검정 펜선 아웃라인,
> 납작한 파스텔 채색, 음영과 그라데이션 없음. 앞발을 앞으로 모으고 꼬리를 몸에 감은 식빵 자세,
> 정면을 보고 있음. 점처럼 작고 단순한 눈, 작은 분홍 코, 옅은 볼터치, 짧은 수염.
> 흰색 앞발과 흰 배. 배경은 완전 투명. 정사각형 구도, 캐릭터가 화면 중앙에 꽉 차게.
> 스티커 같은 깔끔한 스타일.

그다음 **같은 대화에서** 표정만 바꿔 5장을 더 요청합니다.

> 방금 그 고양이와 완전히 똑같은 자세·색·선 굵기로, 표정만 바꿔서 그려줘:
> (1) 기분 좋아 눈을 ^^ 모양으로 감고 웃는 얼굴
> (2) 아주 우쭐하고 자랑스러운 얼굴, 입을 벌리고 활짝 웃음
> (3) 시무룩하고 눈물이 살짝 맺힌 얼굴
> (4) 깜짝 놀라 눈이 커지고 입을 벌린 얼굴
> (5) 다쳐서 눈이 X자, 머리에 반창고를 붙인 얼굴

받은 파일을 위 표의 이름으로 저장해 이 폴더에 넣으면 끝입니다.
