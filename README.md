# 스와이프 캣 — 어느 길고양이의 일생

NAN 2026 (NHN Game × AI 해커톤) 사전 과제 출품작.

**오늘도 어떻게든, 골목의 하루가 넘어간다.**

릴스처럼 화면을 위로 스와이프하며 길고양이 한 마리의 일생 50장면을 넘겨보는 수집형 성장 게임.
설치도 로그인도 없이 링크만 열면 시작됩니다.

- **플레이**: https://choongchoongee-star.github.io/swiper/
- 스마트폰 세로 화면 권장. PC에서는 마우스로 끌거나 방향키(↑ ← →)로 플레이할 수 있습니다.

## 어떻게 노는 게임인가

- **조작은 위로 스와이프 하나.** 첫 화면에도 시작 버튼이 없어, 밀어 올리는 동작으로 조작을 익히게 됩니다.
- **카드는 뜨는 순간 판정됩니다.** 대성공·성공·실패·대실패가 카드와 함께 알림으로 뜨고, 스와이프는 다음 장으로 넘기는 동작입니다.
- **여덟 장에 한 번쯤 갈림길**이 나옵니다. 좌우로 고르면 결과를 한 박자 감췄다가 **다음 장의 「결과 카드」**에서 보여줍니다. 이때는 중간이 없어 대성공 아니면 대실패입니다.
- **방향은 플레이어가 정하고, 성패는 운이 정합니다.** 선택은 그 카드의 확률을 바꾸지 않지만, 고른 쪽의 성향(❤️체력 😊행복 🪶능력 ✨경험치)이 쌓여 엔딩이 갈립니다.
- **체력이 0이 되어도 죽지 않습니다.** 사람에게 구조되어 길 생활이 거기서 끝납니다.
- 아기 고양이 → 어린 고양이 → 다 큰 고양이 → 골목의 어른으로 자라며 화면 색조와 판정이 함께 달라집니다.

## 들어 있는 것

| | |
|---|---|
| 사건 카드 | **104종** (좋은 일 42 · 나쁜 일 36 · 일상 23 · 특수 3) |
| 엔딩 | **31종 + 구조 엔딩 4종**, 해금 힌트가 있는 엔딩 도감 |
| 기록 | 오락실식 이름 등록, **전역 명예의 전당 상위 10명** (Firebase RTDB · 실패 시 기기 기록으로 자동 대체) |
| 공유 | 한 판의 결과와 엔딩 도감을 **링크로 공유** — 서버 없이 주소에 결과를 담는다 |
| 그림 | 162장 전부 생성형 AI로 제작 후 직접 다듬음 |
| 소리 | WebAudio로 코드에서 합성 (외부 에셋 없음) |

한 판은 3~4분. 이어서 하기, 한 번 완주하면 열리는 자동 넘기기(2초에 한 장)를 지원합니다.

## 기술

빌드 도구 없는 **바닐라 JavaScript(ES 모듈) + HTML + CSS**. 프레임워크·번들러·외부 라이브러리를 쓰지 않았고,
GitHub Actions로 GitHub Pages에 배포합니다. 서버가 없어 기록은 브라우저 안에만 남습니다.

```
js/cards.js     카드 데이터        js/endings.js   엔딩 판정
js/deck.js      덱 생성            js/storage.js   기록 저장
js/resolve.js   결과 확률          js/cat.js       SVG 고양이
js/state.js     스탯·점수          js/sfx.js       효과음 합성
js/main.js      화면·입력
```

## 개발

정적 사이트이므로 로컬에서 서버를 띄워 확인합니다. ES 모듈이라 `file://`로는 열리지 않습니다.

```bash
python -m http.server 8000
```

`?cards=20`처럼 붙이면 그 장수로 짧게 한 판을 돌 수 있습니다(테스트·영상 촬영용).
