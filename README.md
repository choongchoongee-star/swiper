# Swiper

NAN 2026 (NHN Game × AI 해커톤) 사전 과제 출품작.

릴스처럼 화면을 위로 스와이프하며 길고양이 한 마리의 일생 100장면을 넘겨보는 수집형 게임.
101종의 사건 카드, 31종의 엔딩과 도감, 명예의 전당. HTML5로 만들어 GitHub Pages에서 바로 플레이.

결과는 전부 운이 정한다. 선택지가 있어도 확률은 바뀌지 않는다.

- 플레이: https://choongchoongee-star.github.io/swiper/
- 공모전 요건: [CONTEST.md](CONTEST.md)

정적 사이트이므로 로컬에서 간단히 서버를 띄워 확인합니다.

python -m http.server 8000
